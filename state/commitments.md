# Commitments

Open-loop ledger. One line per item, in this exact format so `bin/loops` can read it:

    - [ ] YYYY-MM-DD | who owes -> who's owed | what | source

- `who owes`: `me` for Sixten, otherwise the person's name.
- Date is the due date; use `????-??-??` when there is none (it will be flagged).
- Mark done with `- [x]`; `end-of-day` moves done items to the archive.
