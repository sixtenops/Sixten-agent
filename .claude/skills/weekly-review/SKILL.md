# Weekly review

## 1. Look back (Mon–Fri just ending)
- This week's top 3 from `state/priorities.md`: done / partial / not, with evidence.
- Time audit from the calendar: hours in meetings vs. focus, split by which
  quarter goal each meeting served ("none" is a valid answer). Present as a small
  table.
- Commitments closed this week (Archive) vs. opened; anything overdue > 7 days.
- Decisions logged this week; any `Revisit` dates that have arrived.

## 2. Clean up
- Run `follow-ups`.
- Ledger: every undated or > 2-week-overdue item gets a decision — date it,
  delegate, or drop (ask Sixten; batch the questions).
- `state/people.md`: VIPs or key people with no touch in 3+ weeks → list them.

## 3. Look ahead (next Mon–Fri)
- Calendar: meeting load per day, conflicts, days with no focus time, deadlines.
- Quarter goals: which one is getting no time? Say so plainly.
- Propose next week's top 3 tied to the quarter goals; once Sixten confirms,
  write them into `state/priorities.md` (replace the old week, note its result
  in the review file).
- Suggest calendar changes (decline / shorten / move / protect a block) — as
  suggestions only.

## Output — `briefs/YYYY-MM-DD-weekly.md`
Scorecard (3 lines) · time table · 3–5 observations · proposed top 3 · suggested
calendar changes · questions for Sixten. Commit and push.
